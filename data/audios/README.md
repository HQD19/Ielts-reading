# Listening audio

Use one MP3 per Part: `data/audios/c7/test1/part1.mp3`. Replace book, original source test number and Part (1-4). Paths are case sensitive on GitHub Pages. Each recording starts at zero.

Cambridge 20 Test 1 is available in `c20/test1/part1.mp3` through `part4.mp3`, downloaded from the video in `cambridge_20_test_1_full_questions_and_answers.csv`. Starts in the source recording are 00:01, 06:45, 14:47 and 22:30. Each Part ends at the next Part start; Part 4 runs to the video end at 29:30 because no end timestamp was supplied. `c20/test1/source.json` records the source and boundaries. Other tests still need recordings.

Choose Part audio lets you use a local recording without uploading it. Switching test/Part pauses playback and clears the selected file. Playback positions are remembered while the page remains open. Audio controls are separate from the exam countdown.
